# Study With Me（ドット絵 Study With Me Webアプリ）

画面の中の女の子と一緒に勉強できる Study With Me アプリ。
ビルド不要・純粋な HTML/CSS/JavaScript で動作します。

キャラクターはプロシージャル描画（Canvas図形・CSS簡易パーツ・SVG合成）を
一切使わず、渡してもらった参考シートから切り出した画像アセットを
Sprite Animation として再生する方式です。

## 起動方法

Node/npm 等は不要です。ブラウザの `fetch` を使うため、簡易サーバー経由を推奨します。

```bash
cd study-with-me
python -m http.server 5174
```

ブラウザで `http://localhost:5174` を開いてください。

(Node がある場合は `npx serve .` などでも構いません)

### 各ファイルの役割

- **index.html**: `#room` の中に `layer-background` → `layer-furniture` →
  `layer-character` → `layer-foreground` → `layer-ui` を明示的に重ねる構造。
  キャラクターは背景画像に描き込まず、常に独立したレイヤー（`<img id="char-sprite">`）
  として表示する。これにより背景・家具・キャラクターを個別に差し替えられる。
- **character.js**: `assets/characters/<charId>/<state>/frame_N.png` を
  `setTimeout` で差し替えるSprite Animationエンジン。プロシージャル描画は不使用。
  状態: `idle`（ホーム画面）/ `study`（勉強セッション。ベースの書くポーズと、
  ランダムに挟み込む page-turn/drink/think/stretch/yawn/look-clock/laptop の
  一時遷移で構成）/ `rest`（一時停止中）。STUDY中は30〜120秒おきに直前と異なる
  行動を重み付き抽選し、行動が終わるとSTUDYへ戻る、を繰り返す（詳細はファイル内コメント）。
- **room.js**: `Date().getHours()` から朝/昼/夕方/夜/深夜を判定し、`.room` に
  `time-*` クラスを付与。CSSがそれに応じて `layer-background` の実背景画像を切り替える。
- **timer.js**: `Date.now()` の差分で経過時間を計算するため、タブが非アクティブでも
  ズレない。一時停止中の時間は積算しない。
- **main.js**: スタート/一時停止/終了ボタンのイベント処理、タイマー表示・目標バー・
  休憩までのカウントダウンの更新、吹き出しメッセージの表示を行う。
- **tools/crop_sprites2.py**: 新しい参考シート(RGBA)から各ポーズグループの座標を
  アルファチャンネルベースで検出・等分割し、`assets/characters/girl01/` に保存する。
  グループ座標は `POSE_GROUPS` に定義。シートが変わったら座標を調整して再実行する。

## キャラクターアセットについて（重要な設計判断）

### 1. なぜ `image-rendering: pixelated` を使っていないか

指示では「ドット絵なのでpixelatedを使い、拡大縮小のぼやけを避ける」とのことでしたが、
実際に検証した結果、**この参考シートは固定ピクセルグリッドの本物のドット絵ではなく、
階調のある線画イラスト**でした（125×97pxの1フレームだけで8,318色ものユニークな色を
使用しており、典型的なドット絵ならもっと少ない色数で塗り分けられているはずです）。

このような画像に `pixelated`（ニアレストネイバー拡大）を使うと、なめらかな線が
ガタガタのブロック状に見えてしまい、むしろ「ぼやけ」より悪い見た目になることを
実際に確認しました（前回のシートで一度この状態になり、ご指摘をいただいた経緯があります）。
そのため、現状は `image-rendering: auto`（滑らかな補間）を使っています。

本物の固定グリッドドット絵素材に差し替える場合は、
[css/style.css](css/style.css) の `.char-sprite` にある1行を
`image-rendering: pixelated;` に変えるだけで対応できます（コメントに記載済み）。

### 2. 解像度の上限

キャラクター1フレームは概ね100〜160px四方程度、部屋の背景は約170×90px
（旧シート）です。1枚のシートに大量のポーズを詰め込んでいるため、これが
アセットの解像度の上限です。表示サイズはこれに対して大きく拡大しすぎないよう、
控えめな倍率にとどめています。もっとシャープにしたい場合は、1ポーズだけを
単体で書き出した、もっと解像度の高い画像素材が必要です。

### 3. 背景とキャラクターの由来が異なる（既知の制約）

新しい参考シートにも部屋のビジュアル（左上の1枚絵）がありましたが、
**そこにはキャラクターが直接描き込まれていました**。指示の「背景にキャラクターを
描き込まない・レイヤー分離する」という要件を満たすには使えなかったため、
現在の部屋背景は前回のシート（キャラクターが写っていない空の部屋画像）を
引き続き使用し、キャラクターだけを新しいシートの高品質な絵に差し替えています。
そのため、背景とキャラクターの絵柄の世代がやや異なります。空の部屋だけの
背景素材（新シートと同じ絵柄のもの）をもらえれば、差し替えます。

### 4. 切り出し精度について

`tools/crop_sprites2.py` はグループ幅をポーズ数で均等分割する方式のため、
まれに隣のポーズの端が数ピクセル入り込むことがあります。気になる箇所があれば
該当グループの座標を微調整して再実行してください。

## 実装済み機能

- ホーム画面: 部屋の背景、女の子の待機アニメーション（実画像フレームをランダムな
  間隔で切り替え）、「勉強を開始する」ボタン（キャラクターに重ならない位置に配置）
- 勉強中画面: 正確な経過時間タイマー、目標時間に対する進捗バー、次の休憩までの
  カウントダウン、一時停止/再開（一時停止中は「休憩する」ポーズで静止）、
  終了（確認ダイアログ→ホームへ戻る）
- 勉強セッション中は「書く」ベースポーズを基本としつつ、30〜120秒おきに
  ページをめくる/飲み物を飲む/考える/伸びをする/あくび/時計を見る/PCを見る、
  のいずれかへランダムに（直前と同じ行動が連続しないように重み付き抽選で）
  一時遷移し、また書くポーズへ戻る、を繰り返す
- 現在時刻に応じた部屋の雰囲気変化（朝/昼/夕方/夜/深夜で背景画像そのものが切り替わる）
