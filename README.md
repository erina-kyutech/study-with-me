# Study With Me（ドット絵 Study With Me Webアプリ）

画面の中の女の子と一緒に勉強できる Study With Me アプリ。
ビルド不要・純粋な HTML/CSS/JavaScript で動作します。

現在の実装範囲: **STEP1（ホーム画面）+ STEP2（勉強中画面・タイマー）**

## 起動方法

Node/npm 等は不要です。ブラウザの `fetch`/モジュール分離を使わない構成ですが、
`file://` から直接開くと一部ブラウザで挙動が不安定なため、簡易サーバー経由を推奨します。

```bash
cd study-with-me
python -m http.server 5174
```

ブラウザで `http://localhost:5174` を開いてください。

(Node がある場合は `npx serve .` などでも構いません)

## ファイル構成

```
study-with-me/
├── index.html          画面のHTML構造（部屋・ホーム画面・勉強中画面）
├── css/
│   └── style.css        部屋の見た目、時間帯によるスタイル切り替え、UI
├── js/
│   ├── character.js     女の子をcanvasにプロシージャル描画 + 状態管理(IDLE/STUDY)
│   ├── room.js           現在時刻から部屋の時間帯クラスを切り替え、壁掛け時計を更新
│   ├── timer.js           実経過時間(Date.now基準)で正確に計測するタイマークラス
│   └── main.js            画面遷移・ボタン操作・各モジュールの初期化
└── README.md
```

### 各ファイルの役割

- **index.html**: `#room`（部屋の背景・家具・キャラクターcanvas）を土台に、
  `#home-screen` と `#study-screen` を重ねて表示/非表示を切り替える構成。
- **character.js**: キャラクターは画像ファイルを使わず、34×36の小さなグリッドに
  楕円・矩形を描画する自作の「プロシージャル・ドット絵」方式。呼吸・まばたき・
  執筆モーションを `requestAnimationFrame` + 実時間ベースの乱数タイミングで制御。
- **room.js**: `Date().getHours()` から朝/昼/夕方/夜/深夜を判定し、`.room` に
  `time-*` クラスを付与。CSSがそれに応じて空の色・照明の点灯などを切り替える。
- **timer.js**: `setInterval` の呼び出し回数ではなく `Date.now()` の差分で経過時間を
  計算するため、タブが非アクティブになってもズレない。一時停止中の時間は積算しない。
- **main.js**: スタート/一時停止/終了ボタンのイベント処理、タイマー表示・目標バー・
  休憩までのカウントダウンの更新、吹き出しメッセージの表示を行う。

## 実装済み機能（STEP1-2）

- ホーム画面: 部屋の背景、女の子の待機アニメーション（呼吸・まばたき・時々ペンを触る）、
  「勉強を開始する」ボタン
- 勉強中画面: 正確な経過時間タイマー、目標時間に対する進捗バー、次の休憩までの
  カウントダウン、一時停止/再開、終了（確認ダイアログ→ホームへ戻る）
- 女の子は勉強中、継続的にペンを動かして書き続ける（同じタイミングで機械的に
  繰り返さないよう、時々「間」を作るランダム要素あり）
- 現在時刻に応じた部屋の雰囲気変化（朝/昼/夕方/夜/深夜で空の色・デスクライトの
  点灯が変化）

## 既知の制約・メモ

- キャラクターのドット絵は画像アセットを使わず、少数の楕円/矩形の組み合わせで
  簡易的に表現したプレースホルダー品質です。後工程で本格的なスプライトに
  差し替えやすいよう、描画ロジックは `character.js` の `draw()` 関数に集約しています。
- レスポンシブは16:9の部屋を中央配置してスケールする方式のため、縦長スマホでは
  上下に余白（レターボックス）が出ます。PC優先の要件を踏まえ、まずはこの形にしています。
- 終了確認は現状ブラウザ標準の `confirm()` を使用（STEP5で専用の終了画面に置き換え予定）。
